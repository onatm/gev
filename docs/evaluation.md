# Evaluation provenance

The evaluation implementation is adapted from Kev at pinned commit
`08ab0b87d27cb5577a3b371ad7ed4e4686b0502b`:

<https://github.com/jaredpalmer/kev/tree/08ab0b87d27cb5577a3b371ad7ed4e4686b0502b>

`metrics.py` is the pure-NumPy metrics implementation, including selective
prediction, calibration, grouped folds, and paired bootstrap semantics. The
golden fixture is captured independently from the pinned formulas and is not
generated by comparing the implementation with itself. Benchmark evaluation
rejects malformed or non-finite predictions before writing rows and records
coverage and calibration provenance in the report.

Local checkpoint inference applies temperature in the evaluation-mode pointer
head exactly once. It records served and restored raw logits; reports expose
`raw_clean`, `calibrated_clean`, and `nll_provenance`. The CLI passes an
additional benchmark temperature of `1`, preventing accidental double
calibration. Evaluation provenance includes the suite/manifest hash, split
source hash, and checkpoint fingerprint.
